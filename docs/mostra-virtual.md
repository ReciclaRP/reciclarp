# Mostra Virtual — ReciclaRP

**Frase de destaque:** Mapa colaborativo de pontos de reciclagem de Ribeirão Preto.

**Resumo:** O ReciclaRP é uma aplicação web que centraliza os pontos de coleta de reciclagem de Ribeirão Preto. Moradores consultam e cadastram pontos de forma colaborativa no mapa, e uma ONG modera as contribuições. O front-end usa Vite e JavaScript puro, sem frameworks. A API REST usa Node.js, Express e SQLite, e concentra autenticação por e-mail, regras de negócio e validações.
